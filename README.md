# Roblox 查询机器人 · 工单系统

PHP + MySQL 工单与知识库系统，专为 `koishi-plugin-robloxsearch` 配套服务而建。
用户自助查知识库、提工单，客服在后台处理，进展通过邮件实时通知。

---

## 一、环境要求

| 项目 | 要求 |
|---|---|
| PHP | 8.0+（推荐 8.1+） |
| 扩展 | `pdo_mysql`、`mbstring`、`json` |
| 函数 | `mail()`（发邮件用）、`password_hash` |
| 数据库 | MySQL 5.7+ / MariaDB 10.2+ |
| Web 服务 | Apache（Nginx 需自行配置 PHP 解析） |

> `GD` 扩展非必需（验证码采用算术题方案，不依赖图片处理）。

---

## 二、安装步骤

1. **上传代码**到网站根目录（或子目录），确保 `config/`、`uploads/` 目录可写：

   ```bash
   chmod -R 755 config uploads
   ```

2. **浏览器访问安装向导**：

   ```
   http://你的域名/install/index.php
   ```

3. 填写：
   - **数据库信息**：地址、端口、库名、账号、密码（库不存在会自动创建）
   - **管理员账号**：用于登录后台
   - 页面下方会实时显示环境检测结果（PHP 版本、扩展、目录权限）

4. 点击「开始安装」，系统会自动建表并写入 **43 条 Roblox 机器人 FAQ** 与初始分类。

5. **安装完成后请删除 `install` 目录**（或至少删除 `install/.installed`）。

### 手动安装（备选）

若服务器不允许网页写配置，可直接编辑 `config/config.php` 填好数据库信息，
再导入 `install/schema.sql`，然后执行 `install/seed.php` 中的种子数据（可用
`install/index.php` 自动完成，或自行写脚本导入）。

## 六、防机器人机制

提交工单前需通过 **4 层验证**（`includes/captcha.php`）：

1. **算术验证码** — 服务端生成算式，答案用 HMAC 签名存入 Session，10 分钟过期、最多试 3 次；
   数字被打散在多个 DOM 节点，脚本难以按文本提取
2. **蜜罐字段** — 两个隐藏输入框，正常用户不可见，机器人填了就直接拒绝
3. **计时陷阱** — 记录表单打开时间，提交间隔 < 3 秒判定为脚本
4. **IP 频率限制** — 同一 IP 每小时最多提交 N 单（后台可配，默认 5）

用户输入的命令文本会自动高亮显示为代码块，便于客服快速识别。

**访客追加回复**（`ticket-view.php`）不要求验证码，以免正常用户频繁跟进时被打扰，改用轻量频控：蜜罐 + 同一会话对同一工单 20 秒内仅可提交一次 + 同一 IP 对同一工单每小时最多 10 条。

FAQ 有用/没用投票走 POST + CSRF 校验，且每个会话对同一条 FAQ 仅可投一次。

## 七、邮件通知配置

后台 → **邮件设置**：

1. 勾选「开启邮件通知」
2. 填写 **发件人邮箱**（QQ 邮箱需用授权码，非登录密码）与名称
3. 「接收新工单提醒的邮箱」填你自己的（可留空）
4. 自定义 4 类模板（提交成功 / 客服回复 / 状态变更 / 工单关闭）
5. 点「发送测试邮件」验证

**通知变量**：`{no}` `{title}` `{link}` `{time}` `{site}` `{status}` `{content}`

> Windows 环境需在 `php.ini` 启用：
> ```ini
> extension=php_smtp.dll
> extension=php_openssl.dll
> SMTP = smtp.qq.com
> smtp_port = 465
> sendmail_from = your@qq.com
> ```

## 九、安全措施

- 密码 `password_hash()` 存储，登录 `password_verify()` 校验
- 全部 SQL 使用 PDO 预处理，无字符串拼接用户输入
- 全部输出经 `htmlspecialchars()` 转义
- 所有表单带 CSRF Token 校验
- 后台登录失败 5 次锁定，递增时长
- 30 分钟无操作自动退出后台
- 上传文件白名单校验 + 随机重命名 + `uploads/.htaccess` 禁止执行脚本
- 敏感目录（`config`/`includes`/`install`）通过 `.htaccess` 屏蔽
- 访客访问工单需持有不可猜测的密钥（邮箱哈希）

**部署后建议**：
```bash
chmod 640 config/config.php     # 防止配置文件被直接读取
rm -rf install                   # 删除安装向导
```

## 十、常见问题

**Q：安装向导打不开 / 提示数据库连接失败？**
检查 `config/` 目录写权限，以及数据库账号密码是否正确。

**Q：邮件发不出去？**
后台「邮件设置」页会显示 PHP `mail()` 是否可用，并列出每次发送的失败原因。QQ/163 邮箱需使用授权码。

**Q：想换表前缀？**
安装时填写即可；已安装的需改 `config/config.php` 的 `db.prefix` 并手动改表名。

**Q：附件上传失败？**
确认 `uploads/` 可写、`upload_max_filesize` 与 `post_max_size` 不小于后台设置的值。

**Q：前台样式不生效？**
浏览器强制刷新（Ctrl+F5），确认 `assets/` 目录可访问。
